# ⚡ Zenith Discord Bot

> **Unbreakable Server Defense & All-in-One Community Management.**

Zenith is a multi-purpose, enterprise-grade Discord bot built to protect, manage, and entertain communities 24/7.

---

## 🌟 Core Modules

### 🛡️ 1. Anti-Nuke & Server Defense
- **Real-Time Attack Shield:** Instantly halts mass-channel deletion, mass-role deletion, unauthorized bot additions, and rogue webhook creation.
- **Auto Punishment:** Configurable trigger responses: **Ban**, **Kick**, or **Role Stripping**.
- **Whitelist Management:** Safe bypass system for trusted owners and co-administrators.
- **Emergency Lockdown:** 1-Click lockdown for the entire server or individual channels.

### 🔊 2. Zenith Voice (Join to Create)
- **Automated Voice Hub:** Creates private, temporary voice rooms on-demand when users join the hub.
- **Interactive In-VC Dashboard:** Direct button controls for channel name, user limit, privacy locks, and host transfers.
- **Smart Cleanup:** Automatically deletes empty temporary voice channels to keep your server clean.

### 🎵 3. High-Fidelity Audio (24/7 Music)
- **Low-Latency Streaming:** Smooth playback with rich sound quality.
- **Full Queue Management:** Queue reordering, skipping, pausing, resuming, and volume control.
- **Track Metadata:** Live Now-Playing embeds with album artwork, duration, and requester credits.

### 🎫 4. Ticket King Pro
- **Multi-Category Panels:** Interactive buttons for General Support, Billing, Staff Applications, and Bug Reports.
- **Staff Workflow:** Priority tagging (Low, Medium, High, Urgent), ticket claiming, and automated HTML transcript logging.

### 💰 5. Economy & Leveling
- **Activity Rewards:** Earn chat XP and server coins for active participation.
- **Leaderboards:** Real-time top-rankings for XP and economy.
- **Daily Rewards & Transfers:** /daily rewards and peer-to-peer /pay coin transfers.

### 🔨 6. Moderation & Utility
- **Staff Enforcement:** /ban, /kick, /timeout, /warn, /warnings, and message /purge.
- **Server Intel:** /serverinfo, /userinfo, /avatar, /botinfo, and /ping.
